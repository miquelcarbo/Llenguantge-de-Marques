Llenguatges de Marques i Gestió d'Informació

1. Introducció a HTML5 i CSS3

HTML5 és el llenguatge estàndard utilitzat per a l'estructuració i presentació de continguts a la web. En combinació amb CSS3, permet dissenyar interfícies modernes, accessibles i completament adaptables.

Nota: És indispensable utilitzar etiquetes semàntiques adequades per millorar l'accessibilitat del lloc web i optimitzar el seu posicionament als cercadors (SEO).

1.1. Cites i Enllaços Externs

A continuació es mostra una definició oficial extreta d'un portal de referència per a desenvolupadors web:

"HTML (Llenguatge de Marques d'Hipertext) és el codi que s'utilitza per estructurar i desplegar una pàgina web i els seus continguts."

Pots consultar la documentació completa i actualitzada a la pàgina oficial de MDN Web Docs.

2. Exemple de Codi Python

Fragment de codi Python trobat a Internet que demostra la definició d'una funció bàsica de suma: 

def calcular_suma(a, b):
    # Funció que retorna la suma de dos nombres
    resultat = a + b
    return resultat

# Cridada a la funció
print("El resultat és:", calcular_suma(15, 25))
